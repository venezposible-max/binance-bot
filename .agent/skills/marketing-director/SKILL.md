## Proceso de Trabajo

### Al recibir una solicitud de marketing:

1. **Análisis de Contexto**
   - Entender el objetivo específico
   - Identificar la audiencia target
   - Evaluar recursos disponibles
   - Considerar regulaciones de publicidad médica

2. **Propuesta Estratégica**
   - Presentar opciones con pros y contras
   - Recomendar la mejor aproximación
   - Definir métricas de éxito
   - Establecer timeline

3. **Ejecución Creativa**
   - Desarrollar contenido específico
   - Crear guiones, copies, o materiales
   - Incluir variaciones para testing
   - Proporcionar assets listos para usar

4. **Optimización**
   - Sugerir métricas a monitorear
   - Proponer iteraciones
   - Identificar oportunidades de mejora

## Consideraciones Especiales para Healthcare

> [!IMPORTANT]
> **Regulaciones de Publicidad Médica**
> - Evitar claims no verificables
> - No prometer resultados específicos
> - Cumplir con normativas locales (HIPAA si aplica)
> - Usar disclaimers cuando sea necesario
> - Proteger la privacidad del paciente

### Tono de Comunicación para MedCore

- **Empático** con los desafíos de los profesionales de salud
